\section{Metodologia}
\label{sec:metodologia}

A análise do dataset Air Quality UCI seguiu um pipeline metodológico implementado em Python com as bibliotecas Pandas, NumPy, Matplotlib e Seaborn. As etapas principais incluíram a descrição e pré-processamento dos dados, análise exploratória univariada e condicional com engenharia de atributos, análise multivariada de correlações e, finalmente, a implementação manual da Análise de Componentes Principais (PCA) para redução de dimensionalidade.

\subsection{Descrição e Preparação do Conjunto de Dados}
\label{subsec:dataset_prep}

Utilizou-se o dataset ``Air Quality UCI" \cite{devito2008}, contendo \textbf{N = 9358} observações horárias e \textbf{D = 15} variáveis (5 sensores MOx, 5 medições de referência GT, 3 variáveis climáticas, Data e Hora), coletadas entre 2004 e 2005.

O pré-processamento iniciou-se com a leitura dos dados, especificando os separadores corretos e tratando o valor \texttt{-200} como ausente (\texttt{NaN}). As colunas \texttt{Date} e \texttt{Time} foram combinadas num índice \texttt{datetime}, estruturando os dados como uma série temporal. A variável \texttt{NMHC(GT)}, com mais de 90\% de dados ausentes, foi considerada não confiável e excluída das análises subsequentes. Para a análise multivariada e PCA, linhas com valores ausentes nos quatro poluentes de referência restantes (\texttt{CO(GT)}, \texttt{NOx(GT)}, \texttt{NO2(GT)}, \texttt{C6H6(GT)}) foram removidas, resultando num conjunto de dados final de \textbf{N = 6941} observações. Linhas duplicadas foram também removidas. O conjunto de dados foi então dividido em \textbf{8 Preditores} (sensores e clima) e \textbf{4 Alvos} (poluentes GT).

\subsection{Análise Exploratória (EDA) e Engenharia de Atributos}
\label{subsec:eda_feature_eng}

A EDA visou caracterizar as distribuições das variáveis e identificar padrões. Foram calculadas estatísticas descritivas (média, desvio padrão, assimetria, quartis) e geradas visualizações (Histogramas, Box Plots, Violin Plots, Séries Temporais) para cada variável numérica.

Para habilitar a análise condicional e temporal, foram criadas novas variáveis:
\begin{itemize}
    \item \textbf{Características Temporais:} Extração de \texttt{month}, \texttt{weekday} e \texttt{day\_period} a partir do índice \texttt{datetime}.
    \item \textbf{Índice de Poluição Composto (CPI):} Os quatro poluentes GT selecionados foram padronizados via Z-score para normalizar suas escalas. O CPI (\texttt{pollution\_index}) foi calculado como a média destes Z-scores por observação.
    \item \textbf{Classes de Poluição (L=3):} O CPI foi discretizado em três classes de igual frequência (\texttt{Low}, \texttt{Moderate}, \texttt{High}), resultando numa \textbf{distribuição de classes} balanceada (\textbf{L=3}).
\end{itemize}
Subsequentemente, a análise univariada foi repetida de forma condicional, agrupando os dados pela \texttt{pollution\_class} e pelas características temporais para investigar variações nos padrões.

\subsection{Análise Multivariada e Correlação}
\label{subsec:multivariate_corr}

Para investigar as relações entre os 8 preditores, foi realizada uma análise multivariada. A correlação linear de Pearson entre todos os pares de preditores foi calculada e visualizada como um \textit{heatmap}, destacando a forte multicolinearidade entre os sensores. Gráficos de pares, coloridos pelas classes de poluição e temporais, foram gerados para inspecionar visualmente a separabilidade das classes e as relações bivariadas.

\subsection{Análise de Componentes Principais (PCA) - Implementação Manual}
\label{subsec:pca_manual}

Conforme requerido, o PCA foi implementado manualmente para reduzir a dimensionalidade dos 8 preditores e identificar as principais fontes de variação. Os passos foram:
\begin{enumerate}
    \item \textbf{Padronização:} Os 8 preditores foram padronizados (média 0, desvio padrão 1) usando Z-score.
    \item \textbf{Matriz de Covariância:} Calculada a partir dos dados padronizados.
    \item \textbf{Decomposição Espectral:} Cálculo dos autovalores e autovetores da matriz de covariância.
    \item \textbf{Seleção e Projeção:} Os autovalores/autovetores foram ordenados. A variância explicada por cada componente foi calculada e visualizada num Scree Plot. Os dados padronizados foram então projetados nos dois primeiros componentes principais (PC1 e PC2) através de multiplicação de matrizes.
    \item \textbf{Visualização:} O resultado 2D foi visualizado num gráfico de dispersão (PC1 vs PC2), colorido pelas classes. Um Biplot e um Círculo de Correlação foram gerados para interpretar a contribuição das variáveis originais aos componentes.
\end{enumerate}

\subsection{Explicando a PCA}

Na ACP - análise de componente principais (PCA - Principal Component Analisy) nós estamos procurando reduzir o
número de preditores do nosso conjunto de dados. Imagine que você possui um conjunto de dados como milhares de
preditores ou indicares. Realizar uma análise de dados em cima desses dados seria algo muito custoso computacionalmente
então para melhorar o processamento desses dados nós podemos usar alguma técnia de compressão de dados, umas das mais 
populares é justament o PCA.

Intuitivamente podemos imaginar a PCA como uma rotação da reta de regração dos nossos dados (\textcolor{blue}{Fig. \ref{fig:pca-example}}). Em utras palavras, dado
um conjunto de dados como uma dada dimenção D (D preditores, indicadores ou caracteristica) podemos traçar a reta de regração
que melhore representa esse dados. Esssa reta será nossa CP1 - componente principal 1 (PC1 - principal component 1). As próximas
componente principais serão conseguidas trassando retas ortogonais a PC1 passando todos pelo mesmo ponto.

Nesse processo soma da variância total dos dados não é alterada. O que é alterado é a importância de cada variável para explicar Os
dados. Ao final da PCA o primeiro componente principal será responável por explicar a maior parte da variação dos dados, a segunda
componente principa PC2 será responsável pola segunda maior parte e assim por diante, como mostrado na \textcolor{blue}{Fig. \ref{fig:scree-plot-duas-barras-percent}}.

Como dito inicialmente, nosso objetivo é reduzir a dimenção dos dados. Isso acontesse porque podemos usar um conjunto de PCs (e.g. PC1,
PC2 e PC3) tudo vai depender de quandos porcento da variância dos dados nós estamos querendo representar. É necessário realizar 
o palanço entre desemplenho e confiabilidade na representação dos dados.
