\begin{abstract}
A análise exploratória de dados (EDA) é um componente essencial da análise de dados, permitindo que analistas e pesquisadores visualizem os dados de forma visual e identifiquem padrões nos dados. O desafio associado ao ambiente de ciência ambiental é que os dados produzidos por sensores químicos são complexos devido à natureza de alta dimensionalidade da maioria dos dados, características ruidosas e multicolinearidade entre as medições. A análise inteligente de dados é fundamental para tomar decisões informadas sobre monitoramento e soluções de gestão da qualidade do ar. Uma análise exploratória de dados proposta ajudará a definir os 8 preditores (5 sensores de óxido de metal e 3 variáveis climáticas) do conjunto de dados ``Air Quality UCI", permitindo caracterizar seus padrões, encontrar redundância e sua capacidade de explicar a poluição. Uma metodologia surgiu para pré-processamento de dados (organização dos dados como uma série temporal e tratamento de valores ausentes), criação do Índice de Poluição Composto (CPI) usando normalização Z-score, e a Análise de Componentes Principais (PCA) aplicada manualmente para redução de dimensionalidade. A EDA foi conduzida em Python usando utilitários de visualização (Seaborn, Matplotlib), e os dados foram apresentados usando gráficos de distribuição, temporais e de correlação. O resultado principal é a exibição do PCA implementado manualmente, indicando padrões claros relacionados ao período do dia e uma boa separação das classes de poluição (`Baixa', `Moderada', `Alta') e validando a técnica de redução de dimensionalidade.
\end{abstract}
