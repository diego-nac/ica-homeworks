Vamos começar pela análise do PCA. Podemos ver pela figura (\textcolor{blue}{Fig. \ref{fig:circulo}}) que poderiamos
dividir os dados em cerca de 3 classes. Cada classe ficaria com práticamente 1 quadrante do
circulo. Se analizarmos como os preditores estão espalhados no circulos podemos propor as 
seguntes classes.

\begin{itemize}[]
  \item [] 1ª: PT08.S3(NOx)
  \item [] 2ª: T, AH e PT08.S4(NOx)
  \item [] 3ª: RH, PT08.S1(CO), PT08.S2(NMHC) e PT08.S5(03)
\end{itemize}

Outro ponto interessante de se notar é que como apenas duas compenente principais no temos
a representação de $77,5\%$ da variancia dos dados. Isso fica claro quando olhamos para o
gráficos de scren plot (\textcolor{blue}{Fig. \ref{fig:scree-plot-duas-barras-percent}}).

Mais um resultado importante é o mostrado na matriz de preditores (\textcolor{blue}{Fig. \ref{fig:correlation-matrix}}). Podemos
notar quais variáveis são diretamente corelacionadas, quais não possui corelação e quais são
inversamente correlacionadas. Isso vai nos auxiliar a entender as componente principais que aparecem no
PCA (\textcolor{blue}{Fig. \ref{fig:correlation-matrix}}).

um conjunto de componentes principais que explicão boa parter (em geral mais que $80\%$) da variância dos dados no dataset.
